# Cards

The business card front as an outlined print file: 94 × 58 mm with the 2 mm bleed, temple teal (#628F8A), white mark and brand row. Generated from `Xiding.art.card()` by `components/src/build-assets.ts`.

- `xiding-card-front.svg` — the front shared by all three cards.

The backs carry names, numbers and addresses in Instrument Sans. Save them from the AssetKit page as PNG at 300 dpi, or outline them in a design tool before print.
