# VI

The source visual identity of 西頂廣仁宮 Xiding Guangren Temple, from `品牌形象-5.pdf` (Adobe Illustrator, 2026-08-28), kept in the repository at `brand/xiding-guangren-vi/` with its original bytes. The PDF is authoritative; these SVGs are extracted from it.

- **Symbol**: the same dot mark this system uses, as white dots on a teal square.

- **Chinese wordmark**: 西頂廣仁宮 in outlined brush calligraphy, traditional characters. Not live type.

- **English wordmark**: Xiding Guangren Temple, set in Times New Roman.

- **Lockup**: symbol over the two wordmarks. The single-colour lockups (teal, white, ivory, sand) knock the dots out of the square, as the laser-cut sign does; white, ivory and sand are for dark grounds.

- **Palette**: six swatches, now the `vi-*` tokens. Their hex values are the PDF renderer's conversions, not a specified Pantone or CMYK standard.

- **Fonts**: the PDF embeds Adobe Song Std Light and Times New Roman. Their licences are not established, so they are not included here.

- **Base files**: `logo-symbol`, `chinese-wordmark`, `english-wordmark`, `logo-lockup` and `color-palette` are each the whole page clipped to one area; prefer the single-colour files for production.

The files here are byte-for-byte copies of `brand/xiding-guangren-vi/brand-assets/*.svg`; `npm run check:ds` fails if they drift. White, ivory and sand versions are for dark grounds.
