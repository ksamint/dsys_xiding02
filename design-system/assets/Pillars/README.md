- `xiding-pillars-dark.svg` — the same for a dark ground: white base and text, 大智 in white, 大礼 dark with a white edge.
- `xiding-pillar-mei.svg` — 大美，眼光: a square plate in temple teal (#628F8A), white type.
- `xiding-pillar-zhi.svg` — 大智，章法: a square plate in black, white type.
- `xiding-pillar-li.svg` — 大礼，分寸: a square plate in white with a black edge, black type.

Use the plates as column heads, avatars for the three sections, and tags on printed matter.
