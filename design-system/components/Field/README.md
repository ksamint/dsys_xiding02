# Field

A labelled single-line input on a `paper` fill with a `line` hairline. Class `xd-field` on the `<label>` that wraps the input.

**You provide** the label and, when it helps, a placeholder that says what happens when the field is empty ("Leave empty to hide").

- The label sits above the input in `muted` at `caption` size, in the language of what is typed: 中文姓名 over a Chinese name, English name over a Latin one.
- Two fields to a row for short values, full width for phone, email, website and address.
- The `line` border is faint by design (about 1.5:1). The label and the `paper` fill mark the field, so every field keeps its label.
