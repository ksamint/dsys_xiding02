# FieldBlock

A brand-teal block with one line and the mark at its edge; `--bleed` runs it edge to edge with the mark cropped.

Was the second `.xd-field`, which also restyled the form Field (it drew as three 320px teal blocks). Member Home's `xd-fieldblock` is now the base; `--bleed`, `--night` and `--short` are the v1.5 field.

Added in v1.7.
