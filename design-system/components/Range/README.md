# Range

A native slider tinted `teal-text`, with its label on the left and the live value on the right. Classes `xd-range` and `xd-label`.

**You provide** the label, the bounds and a formatted value (`100%`, `6`).

- The value is shown in figures, in `muted`, with tabular numerals.
- Use it for continuous quantities: dot size, line weight.
