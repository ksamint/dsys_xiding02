# BrandRow

Names joined by the pair dot, the mark's own two overlapping dots used as a separator. `Xiding.brandRow(['西顶学院', '西顶艺术'], { size, color })` returns inline HTML that takes the surrounding colour.

**You provide** the names, in order, and a font size.

- Use the pair dot wherever two names or two facts sit on one line: sub-brands, a phone number and an email, a date and a place. It replaces the slash, the bullet, the pipe and the middle dot.
- The pair is drawn from the text size: each dot is 0.19em in radius, centres 1.54 radii apart, with 1.5em of space on each side.
- On `brand-teal`, set it at 24px or larger in `brand-white`; smaller white type on teal falls under 4.5:1.
