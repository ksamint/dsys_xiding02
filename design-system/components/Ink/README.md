# Ink

Puts any block on one pillar's ink: `xd-ink--mei`, `xd-ink--zhi`, `xd-ink--li`.

The pages use these for the three bands, plates and dots. In v1.7 they read the `pillar-*` and `on-pillar-*` tokens, so a pillar colour changed here reaches every page. 大礼 keeps a 1px ink hairline so white on white still reads.

Added in v1.7.
