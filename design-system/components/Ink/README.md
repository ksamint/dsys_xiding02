# Ink

Puts any block on one brand's ink: `xd-ink--arts` (西顶艺术, temple teal), `xd-ink--academy` (西顶新知, black), `xd-ink--lifestyle` (西顶时光, white).

The pages use these for the three bands, plates and dots. They read the `ink-*` and `on-ink-*` tokens, so a brand colour changed there reaches every page. 西顶时光 keeps a 1px ink hairline so white on white still reads.

Added in v1.7; renamed after the brands on 2026-11-19 (they were `xd-ink--mei`, `--zhi`, `--li`).
