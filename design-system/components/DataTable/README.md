# DataTable

A hairline table with tabular numerals, a sticky header and row labels in `teal-text`. Classes `xd-table-scroll` and `xd-table`.

**You provide** the columns and rows; the first cell of each row is a `<th scope="row">`.

- Figures are left aligned and stay on one line. Units go in the header.
- Long tables scroll inside `xd-table-scroll` (cap its height) so the header stays in view.
- Rows are separated by one horizontal hairline.
