# LockupMotion

The stacked lockup that opens the Introduction and the Official Site: 40 dots arrive one by one, then 西顶 fades in.

Classes `xd-lockup xd-lockup--assemble`; each circle carries `--i`, its order. It runs once, is still with reduced motion and in print. Keyframes are named `xd-lockup-dot-in` so they do not replace the mark's own `xd-dot-in`.

Added in v1.7.
