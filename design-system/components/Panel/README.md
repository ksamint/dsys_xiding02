# Panel

A `surface` box with a `line` hairline that groups controls: one decision per group, `space-20` between groups. Class `xd-panel`; groups are `<fieldset>` with a `<legend>`.

**You provide** the groups, each with a one- or two-word legend and, where a choice needs explaining, one `xd-hint` sentence.

- Legends are `label` weight. A hint says what the choice does, in one or two plain sentences.
- Buttons go last, stacked.
- Panels sit side by side on `paper`, flat.
