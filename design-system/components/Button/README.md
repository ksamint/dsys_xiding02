# Button

A square-cornered outline button; the primary one is filled with `ink`. Classes `xd-btn` and `xd-btn--primary`.

**You provide** the label: a verb and its object, sentence case ("Download SVG", "Replay assembly").

- One primary button per group. Stack buttons full width with `space-8` between them; labels are left aligned.
- Hover fills with `teal-text` and sets the label in `surface`. The studio hovers to `teal` with a white label, which holds 3.6:1 at 14px, so the system uses the deeper teal.
- Focus is the `focus` ring: 2px solid, 3px offset.
- Labels are text alone, on a square-cornered, flat button.
