# Pillars

一底三柱: 大美, 大智 and 大礼 standing on the value line, the picture of what Xiding teaches. Classes `xd-pillars`, `xd-pillar`, `xd-pillar--mei`, `xd-pillar--zhi`, `xd-pillar--li`, `xd-pillars__base`, `xd-pillars__motto`, `xd-pillars__sentence`; the words come from `Xiding.PILLARS`.

**You provide** nothing: the names, the three words, the three sentences and the value line are fixed.

- Order is 大美, 大智, 大礼. Each pillar carries its name and its one word: 眼光, 章法, 分寸.
- Each pillar has its ink: `pillar-mei` (temple teal), `pillar-zhi` (black in light, white in dark), `pillar-li` (open, with a 1px `ink` edge). The name is written on every pillar, so the inks tell the pillars apart a second time.
- Above each pillar sits its line of work: 美成, 智行, 礼遇.
- The baseline is a 2px `ink` rule. Under it runs the value line, one part under each pillar: 以美成人，以智行事，以礼相遇.
- Under the value line each pillar has its one sentence, in `muted`, broken at its last comma.
- Use it once in a document, where the three pillars are introduced. The same picture scales to signage and to a slide.
