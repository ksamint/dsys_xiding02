# Segmented

A row or a two-by-two block of mutually exclusive choices; the chosen one is filled with `ink`. Classes `xd-seg`, `xd-seg--wrap` and `xd-swatch`, around native radio inputs.

**You provide** two to four options of one or two words each, and one that starts selected.

- Use it instead of a dropdown whenever every option fits on screen.
- Colour options carry an `xd-swatch` dot before the name; the name follows it.
- Two or three options sit in one row; four wrap two by two.
