# Photo

A photo slot that holds its ratio. Empty, it shows the ring mark and the brief for the shot; filled, the image covers it.

`figure.xd-photo` with an inline `aspect-ratio` and a `data-photo-slot` id; put an `img` inside and add `xd-photo--filled` once there is a picture. The caption is the brief the photographer works from: what, from where, what light.

Added in v1.7.
